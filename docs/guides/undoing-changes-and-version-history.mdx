---
title: "Undo and version history"
description: "Undo local edits and restore saved versions without overwriting a newer revision."
---

Undo and redo apply to the current document. A suggested change's Undo action expires after a later edit, account switch or document switch, so it cannot reverse an unrelated action.

Open **History** to name a version or preview an earlier version read-only. The current pending save must finish before a saved version is selected or restored. **Back to now** leaves the preview without replacing your draft.

**Restore this version** checks the current saved baseline. The CV update, **Before restore** snapshot and restored snapshot succeed together or roll back together. A stale, foreign, trashed or locked CV cannot be restored over.

If you close History and start typing while a restore completes, your newer edits remain available as a conflict. A delayed response from an earlier document visit cannot replace the current draft.

If another session saved a newer baseline, resolve the conflict explicitly. **Save my edits as a new copy** preserves the local draft in a separate CV; **Open saved copy** discards the local draft only after the saved copy loads successfully. Failed choices keep the draft.

After a browser restart, a matching local recovery draft is offered for review rather than applied automatically. It is scoped to the account and document, expires after 24 hours, and is unavailable when browser storage is blocked.
