---
title: "Starting and importing a CV"
description: "Review an imported PDF beside its source, or start writing in an empty CV."
---

Choose **New CV**, select Arabic or English for the document, then **Upload an existing CV** or **Write from scratch**. Writing from scratch creates an empty CV and opens Write with the live preview immediately. Its optional **Use confirmed career information** action copies your confirmed facts into this CV; changes here do not update career information. Changing the interface language does not translate saved CV content.

PDF import uses a native text reader. Original attachments are not sent to an AI model. Readable PDFs up to 25 MB and 30 pages are supported; password-protected and scanned files need an unprotected, text-based source or manual entry. Word import is unavailable.

PDF import opens a dedicated review page. On desktop, compare the original PDF beside one selected section; on mobile, switch between **Extracted information** and **Original PDF**. Jump between sections and use PDF page navigation to check the source. Correct missing or highlighted uncertain values, edit any entry, or remove it; partial reading is explicitly identified. Source page labels appear only where a value can be matched to extracted text. A source label records evidence, not factual verification.

**Confirm entry** or **Confirm section** explicitly accepts supported facts into your career information. **Confirm all remaining** reviews the remaining information that has no uncertainty; highlighted entries still need individual review. For a partially read file, bulk confirmation is unavailable: confirm each section or entry individually and review every section before saving. Editing invalidates the affected approval. Unreviewed information remains in this CV only. **Use confirmed career information** copies accepted values into the review without accepting proposed master edits. **Create CV and open editor** creates the CV and accepted fact links together. Retrying the same confirmation creates one CV.

A file choice or review edit alone creates no saved CV or career fact. Unfinished reviews are kept on this device and can be resumed for 24 hours, including after refresh. **Cancel** removes the local review and returns to documents. A confirmation already accepted by the server may have saved the CV before you navigate away; retrying its retained request recovers that CV. A failed confirmation leaves the review available to retry.

If career information changes elsewhere before confirmation, choose **Refresh career information for review**. Your CV corrections remain intact. Changed reused facts stay in the CV without being accepted or linked to a different master value; unchanged confirmed facts can keep their links.
