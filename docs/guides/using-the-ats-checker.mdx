---
title: "Checking PDFs in your private workspace"
description: "Import and review a CV, then check its actual PDF in the authenticated editor."
---

The public `/ats-checker` page points to the private workspace. It has no public upload or anonymous checking flow.

Sign in, choose **New CV**, and import a readable PDF or enter information manually. Review the information and save the CV before opening **Check**. See [Starting and importing a CV](/guides/importing-resumes) and [Reviewing your CV](/guides/checking-your-resume).

The editor reads the selected PDF locally and does not retain extracted text in readiness state. The server PDF-check endpoint requires authentication, ownership and a current saved revision; it recomputes the submitted file's SHA-256 and stores neither the file nor extracted text. A server report identifies submitted bytes and does not prove they were generated from the CV.

Original PDF/Word attachments and contact-bearing legacy full-text reviews are blocked from AI processing. Word import and export remain unavailable. No public score or hiring-success prediction is shown.
